# Fund-Commitment-Pacing-Model

Using the Alexander-Takahashi model, also known as the Yale model, I aim to build a tool that models a fund-of-funds portfolio.

## Research
### Alexander-Takahashi model
Using six inputs, the model projects capital contributions, distributions, and net asset value:
<p align="center">f(RC, CC, L, B, G, Y) --> C, D, NAV </p>
RC = Rate of contribution
CC = Capital Commitment ($)
L = Life of fund (years)
B = Factors describing changes in the rate of distribution over time
G = Annual growth rate (%)
Y = Yield (%)

C = Capital contributions
D = Distributions
NAV = Net Asset Value
